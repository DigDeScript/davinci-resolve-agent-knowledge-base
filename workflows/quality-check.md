# Review, persistence and handoff

> [Start page](../GUIDE.md) · [Tools](../tools/README.md)

## Completion checklist

- **Content:** opening establishes context; events/ideas connect; important actions, reactions and statements remain complete; ending resolves the sequence. Repetition serves the brief. Review the entire film for pacing, not only its cuts.
- **Picture:** inspect each join and meaningful shot in motion; look for accidental camera turns, unrelated frames, crop/orientation errors and distracting exposure/color changes. Review titles/overlays only if used.
- **Sound:** listen across every join and through the full edit for cut words, clicks, doubled sounds and distracting ambience/level changes. Measure the actual final mix, not only source clips. Apply a delivery loudness target only when specified or justified for the destination.
- **Structure:** validate media availability, intended tracks, clip types, ranges, speed and AV relationships. Check gaps on tracks intended to be continuous; report intentional gaps/overlaps separately. Include transitions in their own inventory rather than counting them as source clips.
- **Persistence:** before/after save and reopen, compare actual ranges, links and every property changed (gain, fades, transition type/position/duration and relevant effects). Reacquire project/timeline/item references after reopening. Protect any current unsaved work before closing. Inspect representative final output too.
- **Handoff:** identify the editable project/timeline, requested exports and source dependencies. State what was measured, frame-inspected, reviewed in motion and listened to, including coverage. A `.drp`/`.drt` is not a media archive.

Use independent evidence labels, for example: `structure: passed`; `frames: all 39 joins`; `motion: opening only`; `listening: not checked`; `persistence: ranges passed, fades not checked`. Overall status stays **draft / review required** if required perceptual checks remain undone. Continue useful authorized work; an unavailable review channel does not require repeated permission questions.

Handoff example: “Editable timeline X, revision Y. No unintended primary-track gaps; original AV mapping preserved. All cut frames checked. Motion/audio review pending at [times and reasons]; full playback still required. Sources remain at [path].” Only write claims supported by recorded checks.
