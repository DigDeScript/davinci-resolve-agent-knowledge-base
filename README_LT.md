# Resolve Agent v1.9

Tai **AI agentams skirta žinių biblioteka**, o ne privalomas montažo planas. Pradėkite nuo [GUIDE.md](GUIDE.md), pagal užduoties poreikius raskite metodą [galimybių indekse](modules/INDEX.md) ir **prieš vykdydami** peržiūrėkite [žinomus spąstus](modules/known-traps.md).

Viešos GitHub repozitorijos `main` šaka skirta peržiūrėtai informacijai. Naujas metodas, nesėkmė ar svarbi pastaba siūloma per atskirą Git šaką ir **Pull Request**. Atskirai įgaliotas tikrinimo agentas išbando PR ir rekomenduoja patvirtinti arba atmesti; tik gavus savininko leidimą pakeitimai prijungiami prie `main`. Žr. [AGENTS.md](AGENTS.md) ir [CONTRIBUTING.md](CONTRIBUTING.md).

Agentui nereikia nutraukti montažo, jei nėra GitHub prieigos arba jis neturi leidimo keisti biblioteką: užtenka pabaigoje pateikti ataskaitą apie atradimą, kurią vėliau galima paversti PR. Ne kiekvienas montavimo veiksmas reikalauja naujo įrašo – tik pakartotinai naudinga patirtis.

**Svarbu:** „patvirtinta“ reiškia peržiūrėtus įrodymus nurodytomis sąlygomis, o ne garantiją visoms Resolve versijoms. Įrankių patikra nepakeičia tikros vaizdo judesio ir garso perklausos. Kliento kūrybinis pasirinkimas išlieka svarbiausias.

Biblioteka paveldėta iš v1.8. Paskutiniai nurodyti integraciniai bandymai atlikti su DaVinci Resolve Studio **21.2.0.5**. v1.9 prideda GitHub žinių kaupimo procesą, **naujų Resolve integracinių rezultatų neteigia**. Įrankių naudojimas aprašytas [tools/README.md](tools/README.md), ankstesnė patirtis – [evidence/resolve-21.2.0.5.md](evidence/resolve-21.2.0.5.md).
